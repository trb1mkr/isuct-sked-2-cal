# 📅 ISUCT-SKED-2-CAL
Приложение для парсинга расписания химкека в формат .ics для использования в сторонних календарях (Google Calendar, Apple Calendar, Microsoft Outlook и т.д.). Также предполагается настройка представления пары с помощью Excel.  

![Google Cal Widget](assets/phone.jpg)  
*Я всегда в одном свайпе от имени отчества преподавателя*

## ⚙️ Как работает?
1. Из интернета скачивается актуальное расписание
2. В расписании находится указанная группа
3. Из интернета скачивается список преподавателей ИГХТУ
4. Сопоставляется фамилия и инициалы преподавателей с их полными ФИО
5. Из полученной информации формируется Excel документ
6. Вы в полуавтоматическом режиме настраиваете представление пар в Excel документе
7. После настройки возвращаемся к консольному приложению и нажимаем Enter
8. Формируется кастомное расписание в виде календаря
9. ???
10. Profit

Инструкции выводятся в консоль во время работы программы и будут написаны в сформированном Excel документе.

## 🤔 FAQ
### Почему после импорта пары не покрашены в соответствии с типом (как на скриншоте)?
Формат .ics не может содержать информацию о цвете события. Пары на скрине окрашены вручную. Достаточно изменить цвет первых пар на обеих неделях и в Google Календаре можно выбрать: "Это и последующие мероприятия".
### Как мне не забыть про это замечательное, невероятно крутое приложение на следующий семестр?
Автоматически генерируется событие, которое напомнит о приложении (для 1 полугодия в январе, для 2 в сентябре)
